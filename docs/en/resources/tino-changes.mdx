## 28 October 2026

- **Transfer hooks fundamentals:** Added [Transfer hooks](/docs/en/solana-fundamentals/transfer-hooks) to Solana fundamentals, with a sidebar entry, a card on the chapter landing page, and fallback redirects for the 13 locales. The page covers the Token-2022 execution order, the extra-account metadata list, an amount-limit example, and why a hook-enabled mint does not mean Raydium supports it. It was checked with `mint validate`, `sync-locales.py --check`, and a local `mint dev` render at desktop and mobile widths in dark mode. No upstream PR has been opened.
- **Contribution standards:** Added `CONTRIBUTION_STANDARDS.md` at the repository root. It sets out what a reviewer expects from a docs issue or pull request, how to cite and verify claims, how to report a contradiction between pages, and the steps to run before opening a PR. It extends `CONTRIBUTING.md` and is excluded from the published site.
- **Branches:** Merged all work into `main` and removed the other branches from this repository. The closed upstream pull requests ([#14](https://github.com/raydium-io/raydium-docs-v1/pull/14), [#15](https://github.com/raydium-io/raydium-docs-v1/pull/15) and [#18](https://github.com/raydium-io/raydium-docs-v1/pull/18)) keep their history on GitHub.
- **Upstream comparison:** Regenerated the files in `public/tino-changes` so they include the Transfer hooks page and the French fixes. They still compare against upstream commit `3699439`. Upstream has since added five commits, and those are not counted as differences from this checkout.
- **Change tracking:** Added this page as its own **Tino changes** tab in the navigation. Each locale redirects to this English page, and the page is linked from the [Resources](/docs/en/resources) index.
- **Upstream comparison:** Added `scripts/generate-upstream-diff.py`, which compares this checkout with Raydium's upstream docs and writes the results to `public/tino-changes`. You can download the [content diff](https://raw.githubusercontent.com/trilltino/raydium-docs-v1-tino/main/public/tino-changes/upstream-content.patch), the [path inventory](https://raw.githubusercontent.com/trilltino/raydium-docs-v1-tino/main/public/tino-changes/upstream-diff.json), and the [Owner API PR patch](https://raw.githubusercontent.com/trilltino/raydium-docs-v1-tino/main/public/tino-changes/owner-api-farm-rewards.patch).
- **Repository links:** Pointed change and diff links at the renamed Tino repository.
- **Locale sync:** Ran `scripts/sync-locales.py` so locale navigation and fallback redirects match the English tree.
- **Build fixes:** Fixed three French pages that stopped `mint validate` from passing. The CLMM instructions page ended mid-sentence inside an open `<Warning>` block, so I finished the sentence and closed the block. The rest of that page remains untranslated. Two French changelog pages used « » as frontmatter quotes, which is invalid YAML, so I replaced them with straight quotes.
- **Mintlify ignore rules:** Excluded `research_notes/` and `reports/` from the Mintlify scan.
