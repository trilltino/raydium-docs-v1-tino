<Warning>
  LaunchLab is a **permissionless** platform. Anyone can create a token with any name or ticker at any time. There is no vetting process. Always research a token independently before purchasing. This page explains mechanics only and does not constitute financial advice.
</Warning>

## What LaunchLab tokens are

LaunchLab tokens trade against a program-managed bonding curve during fundraising. Price behavior depends on the selected curve: constant-product and linear curves change price as supply is bought or sold, while a fixed-price curve keeps its configured price constant.

Reaching the funding threshold changes the launch to `Migrate`. The authorized migration wallet must then create the CPMM pool before the launch reaches `Trade`. Normal pool trading is not available merely because the threshold has been reached.

## Before you buy

### Verify the token and launch

- Verify the token's mint address against a source you trust. Scammers can create tokens with identical names and logos.
- Verify the quote mint so you know which asset you are spending and which asset any creator or referral fees use.
- Check the launch state. Curve buys and sells apply in `Fund`; `Migrate` is an intermediate non-trading state; CPMM trading applies after `Trade`.
- Review the curve type, funding target, amount sold, remaining curve supply, and current quote.
- Current LaunchLab initialization revokes the base mint authority when it mints the full supply. Verify this on the actual mint rather than treating it as a check to perform only at graduation.
- For a Token-2022 launch, inspect its extensions, transfer-fee rate and cap, transfer-fee config authority, and withdraw-withheld authority.
- Inspect creator and platform history if available. No single check establishes that a token is safe.

### Understand the fees

A curve trade can include separate protocol, platform, creator, and referral components:

```text
protocol_fee = protocol rate × trade amount
platform_fee = platform rate × trade amount
creator_fee  = creator rate × trade amount
referral_fee = share fee rate × trade amount, when a referrer is supplied
```

The rates use their configured denominators and integer arithmetic. The program rounds each component in base units, so a displayed decimal estimate can differ slightly from the transaction's exact balance changes. Read the quote and confirmation rather than assuming that a referral link changes only the token price.

### Understand the curve mechanics

Do not assume every buy raises price or every sell lowers it. That describes price-responsive curves, not fixed-price launches. For price-responsive curves, a large trade can move execution before your transaction lands. Use the quote and slippage bound to limit what you accept.

## Step-by-step: buying via the UI

1. Navigate to [raydium.io/launchpad](https://raydium.io/launchpad) and find the token you want to buy.
2. Click the token page to open its detail view.
3. Connect your wallet if you haven't already.
4. Enter the amount of SOL or the supported quote token you want to spend.
5. Review the **estimated tokens received**, **price impact**, and fee components shown in the UI.
6. Review the **slippage tolerance**.
7. Click **Buy** and approve the transaction in your wallet.
8. After the transaction confirms, verify the token balance and actual balance changes.

<Tip>
  You can sell back to the curve while the launch remains in `Fund`. A launch in `Migrate` is waiting for authorized migration, not ordinary curve trading. After the launch reaches `Trade`, use the standard Swap interface for its CPMM pool.
</Tip>

## Slippage

Slippage tolerance bounds the difference between the quote and the execution you are willing to accept. A low tolerance can cause a transaction to fail when state changes before execution. A high tolerance permits a worse execution within that bound.

The Raydium LaunchLab UI's default was **2.5%** when checked on 2026-11-19. This is a UI default, not a universally safe setting or a recommendation for every launch. Review the actual minimum-received or maximum-spent bound before signing.

## After the funding threshold

The last qualifying trade makes the launch eligible for migration. It does not make any trader an authorized migration caller and does not pay that caller a bounty.

```text
Fund → funding condition met → Migrate
                                │ authorized MigrateToCpswap
                                ▼
                     CPMM pool created → Trade
```

After migration:

- Curve trading stays closed.
- Your tokens remain in your wallet untouched.
- Verify the resulting CPMM pool address and mints before trading through another interface.
- Raydium Swap and aggregators can use the pool after they index it. No fixed indexing or display time is guaranteed.

## Risks

| Risk | Description |
|---|---|
| Liquidity-control risk | Check the actual lock and burn records. Current migrations assign the combined locked-LP Fee Key to the configured platform wallet; creator-owned Fee Keys belong to historical migrations under the earlier model. |
| Migration delay | A launch can meet its threshold and remain in `Migrate` until the authorized wallet executes migration. |
| No graduation | If the launch never meets its funding condition, it remains on the curve. Selling while still in `Fund` can return less quote than you paid. |
| Price and execution risk | Prices and available liquidity can change before your transaction executes. Fixed-price curves remove curve-price movement, not the other token and program risks. |
| Token authority risk | Mint revocation alone does not cover Token-2022 transfer-fee authorities, other extensions, holder concentration, or project control. |
| Fake tokens | Scammers create look-alike tokens. Verify the mint address independently. |
| Smart-contract risk | No on-chain program is risk-free. Only use funds you are prepared to put at risk. |
